## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/omarawad005/Programming-Journey.git
   ```

2. Navigate to the problem or project folder you want to run.

3. Open the `.sln` file using **Visual Studio**.

4. Build and run the program using `Ctrl + F5`.
