## How to run

1. Clone the repository.
2. Open the `.sln` file of any problem in Visual Studio.
3. Build and run (`Ctrl + F5`).

## Repository notes

- Each problem is a separate Visual Studio solution with its source in a `.cpp` file.
- Build outputs are excluded through `.gitignore`.
- Exercises follow the course material and are for learning and practice.
